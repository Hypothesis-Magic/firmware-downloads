# Firmware downloads

[開啟下載頁 / Open downloads](https://hypothesis-magic.github.io/firmware-downloads/)

## 使用方式

1. 輸入管理者提供的 Access Key
2. 選擇專案與版本，下載所需韌體
3. 可選擇記住金鑰，儲存前會先詢問
4. 使用「鎖定」結束操作，或「忘記金鑰並鎖定」移除已記住的金鑰

## Usage

1. Enter the Access Key provided by your administrator
2. Select a project and version, then download the firmware
3. Optionally remember your key after confirming
4. Select **Lock** to end the session, or **Forget key and lock** to remove the saved key
